# WezTerm ショートカットチートシート

このドキュメントは `home/modules/wezterm/keymaps.lua` に基づいています。

## Leader Key

| キー | 説明 |
|------|------|
| `Ctrl+a` | Leader キー（1秒のタイムアウト） |

## ペイン操作

| キー | 説明 |
|------|------|
| `Cmd+d` | 水平分割 |
| `Cmd+Shift+d` | 垂直分割 |
| `Cmd+w` | ペインを閉じる |
| `Cmd+z` | ペインズーム（トグル） |
| `Cmd+Opt+←/→/↑/↓` | ペイン間移動 |
| `Cmd+Ctrl+←/→/↑/↓` | ペインサイズ調整（5単位） |

## タブ操作

| キー | 説明 |
|------|------|
| `Cmd+t` | 新規タブ |
| `Cmd+1〜8` | タブ1〜8に移動 |
| `Cmd+9` | 最後のタブに移動 |
| `Cmd+Shift+[` | 前のタブ |
| `Cmd+Shift+]` | 次のタブ |
| `Cmd+Shift+{` | タブを左に移動 |
| `Cmd+Shift+}` | タブを右に移動 |

## フォント

| キー | 説明 |
|------|------|
| `Cmd++` | フォントサイズ拡大 |
| `Cmd+-` | フォントサイズ縮小 |
| `Cmd+0` | フォントサイズリセット |

## ワークスペース

| キー | 説明 |
|------|------|
| `Cmd+Shift+s` | ワークスペース選択（Fuzzy） |
| `Cmd+Shift+n` | 新規ワークスペース |

## コピー・検索

| キー | 説明 |
|------|------|
| `Cmd+f` | 検索 |
| `Cmd+Shift+c` | コピーモード |
| `Cmd+Shift+Space` | Quick Select |

## その他

| キー | 説明 |
|------|------|
| `Cmd+Shift+p` | コマンドパレット |
| `Cmd+Shift+r` | 設定リロード |
| `Cmd+Shift+l` | デバッグオーバーレイ |
| `Cmd+Enter` | フルスクリーン |
| `Shift+PageUp/Down` | ページスクロール |

## Leader キーバインド

`Ctrl+a` を押した後に以下のキーを入力:

| キー | 説明 |
|------|------|
| `s` | Setting Mode起動 |
| `z` | 直前のコマンドと出力をコピー |
| `b` | バッファをNeovimで表示 |

## Setting Mode

`Ctrl+a` → `s` で起動:

| キー | 説明 |
|------|------|
| `h/j/k/l` | ペインサイズを1単位調整 |
| `1〜9` | ペイン高さを10%〜90%に設定 |
| `Ctrl+1〜9` | ペイン幅を10%〜90%に設定 |
| `Esc` / `q` / `Ctrl+c` | モード終了 |

## マウス操作

| 操作 | 説明 |
|------|------|
| 右クリック | ペースト |
| `Cmd+クリック` | リンクを開く |
| トリプルクリック | 行全体選択 |
